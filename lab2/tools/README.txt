Как запустить тест алгоритма синуса без DSP-платы
====================================================

Файл: test_sin_lab2.c

Что это
-------
Автономный тест алгоритмов sin_chebyshev() и sin_cordic() из
../Lab_IQSINDAC/Peripheral_isr.c. Компилируется и выполняется прямо
на PC обычным компилятором (gcc), без Code Composer Studio и без
платы TMS320F28335.

Почему это возможно
--------------------
IQmathLib.h поддерживает два режима (переключаются макросом MATH_TYPE):

  - IQ_MATH    — настоящая фикс-поинт арифметика для DSP. Использует
                 интринсики компилятора TI cl2000 (например __IQmpy),
                 которые понимает только сам TI-компилятор под набор
                 команд C28x. Обычный gcc это не скомпилирует.

  - FLOAT_MATH — все операции (_IQmpy, _IQdiv, _IQsin и т.д.) заменяются
                 на обычную арифметику с float и вызовы из <math.h>.
                 Полностью переносимо, компилируется любым компилятором.

Тест собирается с MATH_TYPE=FLOAT_MATH, поэтому весь код алгоритма
(quadrant_reduce, sin_chebyshev, sin_cordic) выполняется как есть,
один в один, только на float вместо фикс-поинта.

Вместо реального аппаратного таймера, который в timer0_isr() на плате
инкрементирует Time по прерыванию, тест сам в цикле for увеличивает
Time на константный шаг Time_Delta — это и есть способ проверить
алгоритм без железа, которым пользуемся здесь.

Как собрать и запустить
------------------------
Открыть терминал в папке lab2/tools и выполнить:

    gcc -I "../Lab_IQSINDAC" -DMATH_TYPE=FLOAT_MATH -lm test_sin_lab2.c -o test_sin_lab2.exe
    ./test_sin_lab2.exe

Что покажет вывод
------------------
Таблицу: Time, эталонный sin() из math.h, значения sin_chebyshev()
и sin_cordic(), и абсолютная ошибка каждого метода относительно
эталона. В конце — максимальная ошибка по всему периоду 0..2*PI.

Если максимальная ошибка в пределах ~0.0001-0.001 — алгоритм
аппроксимации работает корректно.
